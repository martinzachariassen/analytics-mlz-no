Everything the tracker does

Each button sends a real event through /api/script.js to POST /api/event. Watch it arrive in Realtime within a few seconds.

Page views in a single-page app

The links at the top use history.pushState. The tracker wraps it, so every navigation is a page view. The same URL twice in a row counts once.

Dashboard: Overview → Top pages, Pages → entry and exit pages

Custom event from an attribute

No JavaScript: data-mlz-event="newsletter-signup". Every extra data-mlz-event-* attribute becomes a property.

Dashboard: Events, and the newsletter-signup goal

Custom event from JavaScript

window.mlz?.track("name", props) for anything an attribute can't express, here with a plan and a number of seats.

Dashboard: Events → open the event to see its properties

Outbound links

Clicks on links to other sites send an outbound-link event with the origin and path only, never the query string.

Dashboard: Events → outbound-link

litestream.io ↗ github.com ↗

Campaigns (UTM tags)

The query string is dropped, except utm_source, utm_medium and utm_campaign.

Dashboard: Sources → UTM source, medium, campaign

Goals

Fjord Labs Blog has three goals: the newsletter-signup and contact-submit events, and visits to /contact. Send the form on the Contact page to hit two at once.

Dashboard: Overview → Goals, with conversion rate

Tracking pixel (no JavaScript)

For READMEs and emails: an image request to /api/pixel.gif counts as a page view, or an event with &e=. Turn on Tracking pixel in the site's settings first.

Dashboard: Realtime, Pages → /readme; Events → email-open

Privacy by design

No cookies, nothing in local storage, no IP address or raw user agent stored. Visitors are counted with a salted hash that changes every day. Bots are filtered out.

Details: docs/privacy.md

Colours

          
The UI is greyscale, and colour means data. mlz violet is the main data colour and the brand; grey is the comparison; green and red only mean up and down; five muted series colours are used in a fixed order when a chart compares categories. Rules: docs/development/colours.md.
